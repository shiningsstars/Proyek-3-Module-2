# Portofolio Hasya

Landing page portofolio interaktif yang dibuat menggunakan HTML, CSS, dan Vanilla JavaScript.

Project ini merupakan pengembangan dari landing page dengan menambahkan beberapa fitur interaktif menggunakan JavaScript.

## Fitur

- Navigasi menu mobile buka dan tutup
- Daftar proyek ditampilkan dari array of objects
- Filter proyek berdasarkan kategori
- FAQ accordion
- Validasi form kontak
- Tombol kembali ke atas
- Perubahan tema menggunakan class

## Teknologi

- HTML
- CSS
- Vanilla JavaScript

## Cara Menjalankan

1. Buka folder project di VS Code.
2. Pastikan extension **Live Server** sudah terpasang.
3. Buka file `index.html`.
4. Klik **Go Live** di bagian kanan bawah VS Code.
5. Project akan terbuka di browser melalui local server.
